更新器独立维护，内置固件可能较旧；请下载最新固件并在更新器中手动选择。旧版本可在 Git 标签和提交历史中查找。

1. 连接设备，长按约 6 秒进入安全更新模式。
2. 打开更新器，手动选择下载的最新 vault.pvfw，核对目标版本。
3. 粘贴下面的固件包 SHA256，点击更新，在设备上输入 PIN。
4. 保持供电，等待完成并重启，核对版本和原有记录。


## 固件更新内容

# 固件 1.0.6

- 记录字段顺序：USERNAME → PASSWORD → WEBSITE → DELETE RECORD；记录列表与删除确认保留。
- Beta：每位 PIN 输入前随机排列 0–9，设置、确认、解锁、修改及退回上一位均适用。使用硬件 RNG、Fisher-Yates 和拒绝采样；滚动不调用 RNG。随机数读取失败时禁止确认该位，可点击重试。
- 原 PIN 和数据库格式不变；用户名/密码仍遮挡。
- 只更新应用。现有引导程序中的升级授权 PIN 输入不变；不更新首烧镜像和更新器。
- 编译成功，尚未实板验证本版操作和耗时；随机顺序不能防止直接观察屏幕。

使用现有更新器加载同目录 vault.pvfw，并按设备提示授权。不要用构建目录的 bin 文件刷写。SHA256 见 SHA256.txt。


更新器 1.0.3 移除了摘要复制按钮及可选中的摘要框，隐藏内部安全版本数字，保留发行版号、外部 SHA256 核对、设备 PIN 授权和验签。内置固件与独立包均为 1.0.6。

## 验证状态与边界

已完成编译和签名；本次应用界面、随机 PIN 操作和耗时仍需实板验证。安全引导与芯片保护已在测试板确认，完整升级和维修流程不宣称量产验证通过。
六次错误 PIN 会清空记录。更新仍需设备签名验证和 PIN 授权，SHA256 不能替代它们。更新后不允许降到更低的内部安全版本。
本仓库分发资料录入软件、更新器与应用固件，不含私钥、设备数据、首烧镜像或完整源工程。空白板不能使用此更新器首次安装。

## 版本管理

main 始终放置当前配套更新器和最新固件；release.json 分别记录两者版本。历史版本使用 firmware-vX.Y.Z / updater-vX.Y.Z 标签，不覆盖已发布标签。
