# Password Vault

当前更新器 **1.0.2** · 设备固件 **1.0.4** · 内部安全版本 **5**。

## 资料录入

- [下载 Windows 资料录入软件](https://github.com/799676583/PasswordVault/raw/refs/heads/main/PasswordVaultEntry.exe)
- [录入操作说明](ENTRY.md)

连接设备 → 设备解锁并开启 PC CONFIG → 软件连接设备 → 填写网站名、用户名、密码 → 保存 → 在设备上确认。

## 下载和更新

- [Windows 更新器](PasswordVaultUpdate-v1.0.2.exe)（文件页面选择下载原始文件）
- [最新签名固件](firmware/vault.pvfw)
- [SHA256 清单](SHA256.md)

更新器独立维护，内置固件可能较旧；请下载最新固件并在更新器中手动选择。旧版本可在 Git 标签和提交历史中查找。

1. 连接设备，长按约 6 秒进入安全更新模式。
2. 打开更新器，手动选择下载的最新 vault.pvfw，核对目标版本。
3. 粘贴下面的固件包 SHA256，点击更新，在设备上输入 PIN。
4. 保持供电，等待完成并重启，核对版本和原有记录。

```text
8e543f0df6cff7f38deac59e2be557acf74c8ec6f1facbe2d2a0de50751bca25
```

## 固件更新内容

ATECC 通信对照诊断：STM32 硬件 I2C2 约 50 kHz 独立读取，GPIO 100 us 唤醒与 0x00 地址唤醒两种方式，失败后等待 POST 再读；增加 GPIO 电平、OLED 硬件 ACK、HAL 错误码和唤醒返回值。移除 1.0.3 全地址扫描。仅改应用，不写 ATECC 配置/密钥/锁定位，不改保护或数据库。硬件验证待完成。

更新器包括底部固定操作栏、可滚动内容、SHA256 核对及 USB 临时读取失败的限时等待。

## 验证状态与边界

已完成编译和签名；最新应用的显示及 ATECC 通信修正仍需实板验证。安全引导与芯片保护已在测试板确认，完整升级和维修流程不宣称量产验证通过。
六次错误 PIN 会清空记录。更新仍需设备签名验证和 PIN 授权，SHA256 不能替代它们。更新后不允许降到更低的内部安全版本。
本仓库分发资料录入软件、更新器与应用固件，不含私钥、设备数据、首烧镜像或完整源工程。空白板不能使用此更新器首次安装。

## 版本管理

main 始终放置当前配套更新器和最新固件；release.json 分别记录两者版本。历史版本使用 firmware-vX.Y.Z / updater-vX.Y.Z 标签，不覆盖已发布标签。
